## Описание 

<br>
Данный продукт разработан в учебных целях. Веб-приложение для управления задачами позволяет пользователям планировать свои дела по дням недели, назначать ответственных, фильтровать задачи по сложности, а также визуализировать статистику с помощью диаграмм. Проект реализован на HTML/CSS/JavaScript с использованием бэкенда на Python (Flask) и базы данных SQLite, что обеспечивает сохранность данных между сессиями и возможность работы нескольких пользователей.
<br>

## Установка
<br>
Для установки программы нужно зайти в раздел releases и скачать архив с исходным кодом из самого нового релиза, после чего распаковать архив. Затем установить Python и зависимости через командную строку: pip install flask flask-cors. Далее запустить сервер командой python app.py в папке backend и открыть файл index.html в браузере.
<br>

## Использование 
<br>
Данное веб-приложение позволяет пользователям работать с личными задачами. При первом использовании доступна регистрация аккаунта или вход в существующий. Приложение предоставляет функции просмотра задач по дням недели, добавления новых задач с указанием сложности и ответственного, удаления задач, поиска по названию, фильтрации по сложности и просмотра визуальной статистики в виде круговой и столбчатой диаграмм. Данные хранятся на сервере в базе данных SQLite.
<br>

## Разработка 
<br>
Данный проект разрабатывается в рамках учебной практики одним человеком и не требует посторонней помощи. Веб-приложение создаётся с использованием HTML, CSS, JavaScript для фронтенда, Python и Flask для бэкенда, а также SQLite для хранения данных и Chart.js для визуализации.
